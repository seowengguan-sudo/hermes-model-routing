# PENSOLAR — Project Brief (POC)

## Company (verified from pensolar.com.my)
- **Pensolar Sdn Bhd**, Penang, Malaysia. Solar PV system integrator.
- Segments served: **Residential**, **Commercial & Industrial (C&I)**, **Utility Scale**.
- Value props: One-stop (design→permits→procurement→install→commission),
  O&M, Energy Performance Contracting, **RPVI** (Registered PV Investor) offering
  **Zero-CAPEX via PPA / Solar Leasing**. Handles authorities & permits (ST, TNB, SEDA/NEM).
- Pain it sells against: high TNB bills, grid reliance, CSR/sustainability pressure.

## Client for this POC
- **The Director** of PENSOLAR wants **TOTAL control & visibility** across the business.
- Current痛点 (pain): relies on staff/workforce for status; replies are **slow + may be
  inaccurate**; too much "noise" to know *where to focus*.

## POC Objective (from user Q1)
A project-management system giving the Director:
1. Total **Project Management control** (pipeline → install → commission)
2. **Administrative overview**
3. **Accounting summary**
4. **Financial control** (incl. PPA/lease cashflow, CAPEX vs Zero-CAPEX)
5. **Procurement / Purchasing automation**
6. **Executive-ready reports** (one-click summarize → board doc)
7. **HR / workforce arrangement** (who is on which site, utilization)

## Core design principle
> Visibility over noise. The system must **surface exceptions & blind spots**,
> not bury the Director in raw tickets. Async status (not waiting for staff replies).

## Scope decision (recommended for POC)
- Build the **framework** (all 7 modules scaffolded) but go **deep on 2**:
  - **Visibility layer** (director dashboard: exception-driven)
  - **Procurement automation** (highest manual-pain, clear ROI)
- Other 5 modules: structured schemas + mock data, ready to deepen per phase.

## Discovered workflow (to validate with client)
Lead → Site survey → Design → Permits (ST/TNB/SEDA) → Quotation →
Contract (outright OR PPA/lease) → Procurement → Install → Commission →
NEM activation → O&M/handover. C&I adds feasibility + financing model.

## Open questions for client discovery
- How are projects tracked today (Excel, WhatsApp, nothing)?
- What % of delays come from permits vs procurement vs workforce?
- Does Director want mobile or desktop-first?
- Current accounting tool (SQL? Xero? spreadsheet)?
