## Concept: Safe rollout — Shadow → Canary → Enforce, gated by your eval

The conceptual ladder gave you the *parts* and the *trust tests*. This is the **operating procedure** that lets you actually raise the autonomy dial without a 2am phone call. PENSOLAR example throughout (`auto_schedule_crew` guardrail on permit-clearance).

- **Shadow mode = the agent advises, the human decides — but you still score it.** Wire `auto_schedule_crew` to *recommend* a schedule/block decision from live project data; the PM makes the real call. Every recommendation is run through `score_eval.py` against `golden_v1.csv`. If recall on block cases is <100% in shadow, the dial stays at 0 — you've just caught the exact failure the eval exists to catch, with zero career risk.
- **Canary = small real autonomy + full visibility.** Once shadow recall holds, raise the dial one notch: *act on low-risk classes only* (permit already cleared + no open objection → auto-approve schedule), while block decisions stay human-in-the-loop. Log 100% of the canary's actions to a board the Director can see — that's his "total visibility" want, delivered.
- **The gate is recall, enforced CONTINUOUSLY — not a one-time 80%.** Run 5b: gate on recall for safety. In rollout that means: if the live canary ever misses a block case the golden set would have caught, **auto-rollback the dial to 0 and alert**. A one-time 80% eval score (Run 7's sample) is a baseline, not a ship gate. The ship gate = "recall ≥ target on continuous live scoring, with auto-rollback on breach."
- **Quarantine disagreement, don't delete it.** When the agent and the golden set disagree, that row is *new signal*, not noise. Route it to a `review_queue` for human sign-off; if the human agrees the agent was right, it becomes a candidate for `golden_v2` (Run 7: re-audit quarterly). This is how the golden set stays alive instead of rotting.
- **Rollout is a dial, not a switch — and the eval is the hand on it.** Stack (R1) + tool/agentic (R2) told you *what to build*; guardrails (R3) + evals (R5) + golden set (R7) told you *how to trust it*. Shadow→canary→enforce is the procedure that lets you *raise autonomy safely*. That is the move from POC-build to scaling.
